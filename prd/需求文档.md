

# 需求文档

实现需求：

1. 根据微信公众号文章创作 SKILL，将skill的功能界面可视化操作
2. 添加AI配置页面，可以配置中转站和firecrawl搜索配置，中转站支持文本和图片模型
3. 文章的生成流程大致分为初步AI写作(可以调用AI大模型文本接口，或者先调用firecrawl搜索结果后再调用AI大模型文本接口根据结果生成)、去痕、生成封面和段落配图、发布到指定的平台、列入微信公众号、小红书、知乎等平台
4. 添加写作页面，选择文章写作风格、文章主题，可以选择是否调用firecrawl搜索结果后生成，点击开始生成，之后自动生成文章标题和内容。可以选择重新生成。生成之后可以调用AI 写作去痕工具进行处理，然后可以查看原文和处理后的文章内容进行对比。然后可以选择是否生成封面图和文章段落图，生成文章封面图和段落图之后，将段落图插入到去痕后的文章中，进行查看，确认最终效果之后，可以选择平台发布，暂停只发布微信公众号
5. 添加密钥配置页面，每个平台单独一个配置页，微信公众号配置需要：微信公众号 AppID、微信公众号 AppSecret、WECHAT_AUTHOR、WECHAT_AUTO_PUBLISH。
6. 你可以使用next.js进行开发，页面样式需要好看且布局合理
